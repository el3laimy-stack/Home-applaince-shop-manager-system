# ALIkhlas POS — دليل التفعيل Offline

## مفاتيح الناشر (مرة واحدة فقط)

على جهاز ناشر موثوق مثبت عليه Python 3 وOpenSSL 3، نفّذ داخل Frontend/alikhlas_pos:

    python3 tool/license_admin.py generate --directory /secure/alikhlas-keys

يجب أن يكون المسار خارج مستودع Git وبصلاحيات محدودة. الناتج:
- issuer-private.pem: **مفتاح خاص وسري**. لا يوضع في GitHub ولا ملف التثبيت ولا جهاز العميل.
- issuer-public.pem: المفتاح العام. يعرض الأمر قيمة ALIKHLAS_LICENSE_PUBLIC_KEY بصيغة Base64.

أضف المفتاح العام فقط في GitHub → Settings → Secrets and variables → Actions → Variables، باسم ALIKHLAS_LICENSE_PUBLIC_KEY. لا تغيّر زوج المفاتيح مع كل إصدار، وإلا لن تقبل النسخ الجديدة ملفات التفعيل القديمة.

## خطوات العميل

1. شغّل نسخة البرنامج المبنية بالمفتاح العام في جهاز Windows/Linux.
2. قبل تسجيل الدخول تظهر شاشة تفعيل فيها رمز جهاز مكون من 64 حرفًا.
3. يرسل العميل الرمز إليكم عبر واتساب.
4. يسجل المسؤول اسم العميل وجهازه في سجل إدارة داخلي.
5. يصدر المسؤول الترخيص على الجهاز الموثوق:

    python3 tool/license_admin.py issue --private-key /secure/alikhlas-keys/issuer-private.pem --customer "متجر التجربة" --device-id <DEVICE_ID> --output /secure/issued/shop.license

6. أرسل shop.license للعميل كمستند واتساب أو عبر البريد أو فلاشة.
7. يضغط العميل «استيراد ملف التفعيل» ثم يختار الملف. يتحقق البرنامج من Ed25519 ومن بصمة الجهاز.
8. يمكن استخدام التطبيق دون اتصال مستمر بالإنترنت؛ لا يوجد مفتاح سري مخزن داخل التطبيق.

## النسخ والأجهزة البديلة
- نسخ ملف الترخيص أو قاعدة البيانات لجهاز آخر لن يتيح التفعيل العادي لأن البصمة مختلفة.
- الملفات المخزنة محليًا غير مرتبطة بتثبيت برنامج أو SQLite؛ لا تُفقد فواتير العميل عند عدم التفعيل.
- إذا تغيّر Windows MachineGuid أو UUID أو Linux machine-id نتيجة نقل نظام أو إعادة تثبيت، يصدر الناشر ترخيصًا جديدًا للجهاز بعد التحقق من طلب النقل.
- التراخيص الدائمة Offline لا يمكن إلغاؤها فوريًا عن بعد؛ يمكن إضافة تراخيص محددة المدة أو مراجعة دورية Online في مرحلة مستقبلية.

## متطلبات النشر
- لا تُنشر ملفات CI غير المضبوطة بالمفتاح العام: ستكون غير قابلة للتفعيل عمدًا.
- عند إنشاء tag رسمي، يجب أن تكون قيمة ALIKHLAS_LICENSE_PUBLIC_KEY صالحة Base64 بطول 32 بايت.
- يلزم نجاح اختبارات Flutter وPython وWindows/Linux، وتجربة ميدانية على جهاز حقيقي.
- اختبر نسخ الترخيص إلى جهاز ثانٍ، واستيراد ترخيص معدل، وتحديث التطبيق، واستعادة قاعدة البيانات.
- حماية التطبيق محليًا لا تمنع تحليل وإعادة كتابة البرنامج بالكامل. لا تدّعي الحماية المطلقة.

## قانونية المصدر
المستودع سبق نشره للعموم بترخيص MIT؛ تحويله إلى Private لاحقًا لا يلغي الحقوق المكتسبة بالترخيص السابق. يوصى بمراجعة حقوق نشر الإصدارات التجارية الجديدة.

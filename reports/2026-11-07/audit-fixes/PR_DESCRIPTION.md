# Fix offline POS data safety and accounting consistency

تعالج التغييرات عشر مشكلات موثوقية: فقد الفاتورة عند التنقل من تنبيه النسخ، وعدم اتساق صور حزمة النقل، واختلاف الربح وأرصدة الأطراف، ونقص تفاصيل مرتجعات المورد، وتغير هوية الأصناف في الفواتير القديمة، وتعارض الباركود، وتداخل حركات الورديات، وتجاوز مجال المبالغ، واقتصار عدادات الأقساط على المعاينة.

يرفع المخطط إلى 12 والإصدار إلى `1.1.1+11`. تثبت بيانات الأصناف القديمة وقت الترقية مع توضيح مصدرها، وتحمل الوردية المفتوحة حصيلتها السابقة. تبقى القيود والأرصدة والكميات وإيصالات منع التكرار محفوظة. الترقية والنسخ القديمة مدعومة من v3 حتى v11، والنسخ الجديدة تستخدم v12.

التحقق المحلي:

- 227 اختبارًا ناجحًا دون فشل، بما فيها الترقية من كل إصدار مدعوم، وتعديل صورة أثناء النسخ، ورفض مرفق ناقص، وحدود 64 بت وإلغاء الحفظ عند التجاوز.
- `dart analyze lib test`: دون ملاحظات.
- اختبار قفل العمليات: ناجح.

بناء Windows وLinux وحزم التثبيت عبر CI لم يُنفذ بعد بسبب رفض تفويض GitHub المرتبط للكتابة بخطأ 403. محاولة بناء Linux المحلي توقفت عند غياب CMake. يبقى قبول الأجهزة الفعلية وفق `FIELD_ACCEPTANCE_AR.md` مطلوبًا قبل التسليم الإنتاجي.

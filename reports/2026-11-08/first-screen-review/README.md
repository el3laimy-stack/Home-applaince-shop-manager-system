## النطاق

هذه هي الشاشة الأولى لعميل لم ينشئ حسابًا بعد. شاشة الدخول للمستخدم العائد هي الشاشة التالية للمراجعة. لا يتضمن هذا التعديل إعادة تصميم البيع أو لوحة المتابعة أو غيرهما، ولا يغيّر مخطط قاعدة البيانات أو خدمات الحسابات. كل بيانات الاختبار افتراضية.

| المشكلة في الشاشة السابقة | المعالجة |

## المراجعة المستقلة

راجع Agent مستقل متخصص في تصميم الواجهات، للقراءة فقط، عشر لقطات حقيقية من تصيير Flutter والكود المرتبط. اعتمد شاشة الإعداد بصريًا دون ملاحظات Blocker أو Major. عولجت ملاحظاته حول اتجاه الخطوات، ثبات التسميات، مسافة شريط التمرير، ترتيب المعلومات، وشكل الأزرار المعطلة. نجح اختبار ترتيب Tab الذي اشترط المراجع التحقق منه وظيفيًا.

تبقى ملاحظة تجميلية غير مانعة: يمكن موازنة أسطر مجموعات رمز الاستعادة على العرض الضيق لاحقًا. النص الأصلي المنسوخ محفوظ حرفيًا، واتجاه LTR مختبر. هذه مراجعة مستقلة بمعايير الوضوح والاتساق المستلهمة من iOS، وليست اعتمادًا من Apple.

## التحقق

نجح 32 اختبارًا مختلفًا:

- `first_screen_review_test.dart`: 11 حالة، الفاتح والداكن، عرض 1024 و360، تكبير 125%، التحقق من المدخلات، Enter وTab، إظهار السر، منع الإنشاء المكرر، نسخ الرمز، فشل التخزين وإعادة المحاولة، الطباعة الاختيارية، وعرض 320×520 مع محاكاة مساحة لوحة المفاتيح.
- `initial_owner_setup_test.dart`: إنشاء المالك دون كلمة مرور افتراضية معروفة.
- `recovery_access_test.dart`: 3 حالات لاستعادة الدخول وتدوير الرمز وحد المحاولات.
- `liquid_glass_test.dart`: 14 حالة للثيم والتباين وتقليل الحركة وحفظ حالة الشاشة والطباعة وبدء الثيم المحفوظ.
- حالتا `new shop` الموجودتان في `v2_app_test.dart`.
- المرجع البصري `first run setup` في `v2_golden_test.dart`، بعد تثبيته ثم مقارنته دون تحديث.

أُعيدت حالات الشاشة الإحدى عشرة بعد آخر تعديل تجميلي ونجحت. `flutter analyze --no-pub` دون ملاحظات. صُحح اسم المرجع البصري من `login_liquid_glass.png` إلى `first_run_setup_liquid_glass.png`؛ الملف السابق كان يصوّر الإعداد بالفعل.

تشغيل الاختبارات من `Frontend/alikhlas_pos`:

```sh
flutter test --no-pub test/v2/first_screen_review_test.dart test/v2/initial_owner_setup_test.dart test/v2/recovery_access_test.dart test/v2/liquid_glass_test.dart
flutter test --no-pub test/v2/v2_app_test.dart --plain-name 'new shop'
flutter test --no-pub test/v2/v2_golden_test.dart --plain-name 'first run setup'
flutter analyze --no-pub
```
